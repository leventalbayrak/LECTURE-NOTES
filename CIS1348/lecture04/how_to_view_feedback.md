# How to Find Your Feedback

I leave feedback by branching off the exact commit you submitted. The branch is named `feedback_<date>` (e.g. `feedback_2026-09-19`), and my comments are in Markdown files inside that branch.

## Steps

1. Go to your repo on GitHub.
2. Click the **branches** dropdown (or go to the "Branches" tab).
3. Look for branches starting with `feedback_` — there may be several over time.
4. Pick the one with the **most recent date** — that's your latest feedback.
5. Open it and read the `.md` file(s) I added.

## Note

If you get feedback again later, a new `feedback_<newer date>` branch will appear — always go with the newest one.
